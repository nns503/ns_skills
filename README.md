# NS Skills

직접 만들고 사용하는 AI 에이전트 스킬을 모으는 개인 저장소입니다. **설명, 사용 예시, 작업 지침은 한국어를 기본으로 작성합니다.**

스킬 원본은 `skills/` 한 곳에서 관리하고, 필요한 스킬을 플러그인으로 묶어 설치할 수 있도록 구성합니다. [anthropics/skills](https://github.com/anthropics/skills)의 저장소 구성을 참고했으며, 이 저장소는 독립적으로 작성하는 개인 프로젝트입니다.

> 현재는 초기 구조와 작성 템플릿만 있습니다. 설치할 수 있는 스킬이나 플러그인은 아직 등록하지 않았습니다.

## 저장소 구조

```text
ns_skills/
├── README.md                         # 한국어 소개와 스킬 목록
├── AGENTS.md                         # 저장소 작업 규칙
├── skills/                           # 실제 사용하는 스킬 원본
│   └── <skill-name>/
│       ├── SKILL.md                  # 한국어 설명과 실행 지침
│       ├── references/               # 필요한 경우에만 추가하는 참고 자료
│       ├── scripts/                  # 필요한 경우에만 추가하는 실행 도구
│       └── assets/                   # 필요한 경우에만 추가하는 템플릿·리소스
├── template/
│   └── SKILL.md                      # 복사해서 수정하는 작성용 템플릿
├── docs/
│   ├── creating-skills.md            # 한국어 스킬 작성 안내
│   └── marketplace.md                # Claude Code·Codex 배포 구성 안내
├── .claude-plugin/marketplace.json   # Claude Code용 목록: 현재 비어 있음
└── .agents/plugins/marketplace.json  # Codex용 목록: 현재 비어 있음
```

`references/`, `scripts/`, `assets/`는 모두 선택 사항입니다. 필요하지 않은 폴더는 만들지 않습니다.

## 새 스킬 만들기

1. `skills/<skill-name>/` 폴더를 만듭니다.
2. `template/SKILL.md`를 새 폴더에 복사합니다.
3. 영문 식별자와 한국어 설명·작업 지침을 채웁니다.
4. 실제 요청으로 동작을 확인하고, 확인한 환경과 사용 예시를 이 README에 추가합니다.
5. 묶음으로 배포할 때 해당 환경의 마켓플레이스 목록에 등록합니다.

자세한 내용은 [스킬 작성 안내](docs/creating-skills.md)와 [마켓플레이스 안내](docs/marketplace.md)를 참고하세요.

## 언어와 호환성

- 폴더명과 `name`은 `meeting-notes`처럼 영문 소문자·숫자·하이픈을 사용합니다.
- `description`, 본문, 사용 예시와 결과물 안내는 한국어로 작성합니다.
- 파일명 `SKILL.md`와 도구·API 식별자는 원래 표기를 유지합니다.
- 특정 제품의 도구가 필요하면 그 환경과 의존성을 명시합니다. 형식이 같아도 모든 에이전트에서 같은 기능이 제공되는 것은 아닙니다.
- 영어 안내가 필요해지면 별도 문서를 추가하되, 한국어 문서를 기본 진입점으로 유지합니다.

## 출처와 라이선스

다른 저장소에서 가져오거나 수정한 자료는 원본 URL, 라이선스와 변경 내용을 함께 기록합니다. 이 저장소 전체를 특정 라이선스로 배포하는 결정은 아직 하지 않았습니다.
